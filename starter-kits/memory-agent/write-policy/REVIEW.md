# 定期复盘 Review

> 记忆的维护动作:提炼、淘汰、校正。没有复盘的记忆系统只会膨胀和腐烂。

## 频率

- 高频任务(每日 cron):每周一次
- 低频任务:每 N 次运行后一次

## 复盘清单

1. **提炼**:working/ 层是否有值得沉淀的条目?按 WRITE-POLICY 三问过滤后转入 long-term/experience
2. **淘汰**:long-term/ 中来源失效、一周内从未被召回、或已被更新的条目 → 删除或归档
3. **校正**:experience/ 中的经验是否被新反例推翻?推翻则改写并记录反例
4. **查询对齐**:retrieval/QUERIES.md 是否覆盖了最近实际需要召回的内容?缺则补查询词
5. **层间泄漏检查**:context/ 的临时内容是否被误写入长期层?

## 输出

复盘结果写入 STATE.md(复盘时间、处理条目数、淘汰数),供下次复盘对比。
