# 指标定义 Metrics

> 3-5 个真实可采集的指标,足够了。指标不可采集就不许写进来。

## 指标表

| 指标 | 定义 | 采集方式 | 采集频率 | 当前值 |
|:---|:---|:---|:---|:---|
| 任务成功率 | PASS / 总运行次数 | checker 判定记录聚合 | 每日 | (填) |
| 重试率 | 触发重试的运行占比 | STATE.md 重试计数 | 每日 | (填) |
| 平均耗时 | 从触发到交付的分钟数 | 运行日志时间差 | 每日 | (填) |
| 人工介入率 | 需要人工升级的占比 | 升级记录 | 每周 | (填) |
| 反测通过率 | regression.json 通过条目占比 | 每次改动后运行 | 每次改动 | (填) |

## 记录格式

每次改动在 baseline 前后各记录一次指标快照,格式:

```text
<日期> <版本> : success=xx% retry=xx% latency=xxmin escalate=xx% regression=xx/xx
```

## 禁止

- 用「体感」「看起来更聪明」作为指标
- 指标超过 7 个——测不过来的指标等于没有
- 改动采集方式却不重录 baseline
