# 写入策略 Write Policy

> 记忆系统的第一道质量闸门:写入时严格,检索时才轻松。

## 分层规则

| 层 | 内容 | 生命周期 | 写入条件 |
|:---|:---|:---|:---|
| context/ | 本会话即时上下文 | 会话结束即弃 | 无门槛 |
| working/ | 当前任务工作集 | 任务结束归档或清理 | 与任务直接相关 |
| long-term/ | 沉淀知识 | 长期,定期淘汰 | 有证据 + 一周后仍有用 + 可检索 |
| experience/ | 成功/失败经验 | 长期 | 含反例与触发条件,不只记结论 |
| evidence/ | 长期记忆的来源 | 与被支撑条目同生命周期 | 每条 long-term/experience 条目必须有 |

## 写入动作模板

```text
写入目标层: <层名>
条目摘要: <一句话>
关联证据: evidence/<id>.md(长期层必填)
召回查询: <未来什么查询词应命中它>
淘汰条件: <什么情况下删除或降权>
```

## 禁止

- 无证据的「结论」直接进 long-term
- 把摘要当证据(摘要是压缩,不是来源)
- 一次会话往长期层倾倒超过 5 条未经复盘的条目
