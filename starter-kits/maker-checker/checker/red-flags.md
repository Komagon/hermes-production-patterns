# Red Flags — 一票否决清单

> Checker 的硬性判定线。任何一条命中,直接 FAIL,不接受「整体尚可」的辩解。
> 按业务自行增补,但每条必须是可机械判定的明确陈述。

## 通用红线

- 产出缺少 schema 必填字段,或字段类型不符
- 编造的事实、数据、引用来源(未经核实的具体数字/链接)
- 产出与任务要求的核心目标明显偏离
- 确定性计算出现算术错误(必须走脚本的步骤用了心算且结果错)
- 泄露密钥、内部路径、用户隐私等敏感信息

## 领域红线(按需补充)

- (示例)代码产出:未经语法检查/测试,或引入已知的废弃 API
- (示例)文章产出:出现未经交叉验证的第二来源事实
- (示例)报告产出:结论没有对应证据条目支撑
